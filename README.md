# 🔐 Auditoria Interna de Segurança — Botium Toys

## 📌 Sobre o projeto

Este projeto apresenta um estudo de caso educacional de uma auditoria
interna de segurança da informação realizada sobre o cenário fictício
da empresa Botium Toys.

O objetivo da auditoria foi avaliar a postura de segurança da organização,
identificar riscos, analisar controles existentes, verificar requisitos
de conformidade e propor recomendações para redução dos riscos encontrados.

> Este projeto foi desenvolvido para fins educacionais e de portfólio
> em cibersegurança.
